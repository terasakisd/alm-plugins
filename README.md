# ALM Plugins

広告リンク管理の WordPress プラグイン一式。

| プラグイン | 役割 |
|---|---|
| **ad-link-manager**(広告リンク管理) | 投稿ごとに案件単位で bt ID / キーワードを登録し、広告リンクの表示/非表示をワンクリックで切替するメタボックス |
| **alm-connector**(ALM コネクタ) | 本体を変更せずに、外部の順位管理ツールから案件の読み書き・順位入れ替えを行う REST API を追加 |

## サイトへの導入

1. [Releases](../../releases) から各プラグインの zip をダウンロード
2. WP 管理画面 → プラグイン → 新規追加 → アップロードで有効化

**一度導入すれば、以後の更新は WP 管理画面の更新通知から1クリックで適用できます**
（各プラグインが GitHub のリリースを自動チェックします。WordPress 5.8+）。

## 更新の配布手順（開発者向け）

1. プラグインのコードを修正し、ヘッダの `Version:` を上げてコミット
2. リリースを発行:

   ```bash
   ./release.sh ad-link-manager   # または alm-connector
   ```

   スクリプトがヘッダからバージョンを読み取り、zip を作って
   `<プラグイン名>-<バージョン>` のタグで GitHub リリースを作成します。
3. 各サイトの WP には半日以内に更新通知が出ます
   （すぐ確認したい場合は ダッシュボード → 更新 → 「もう一度確認する」）。

## 注意

- リリースのタグ名（`ad-link-manager-6.8.0` など）とアセット名（`ad-link-manager.zip`）は
  自動更新のキーなので、release.sh を使わず手動で発行する場合も必ずこの形式にすること
- トークン等のシークレットはコードに含めない（コネクタのトークンは各サイトの DB に保存される）
